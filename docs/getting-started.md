# Getting started

## 1. Get the code

```bash
git clone <repo-url> test
```

## 2. Make a change

1. Create a branch: `git switch -c my-change`
2. Edit or add a file under `docs/`
3. Commit: `git commit -am "Describe the change"`

## 3. Share it

Push the branch and open a pull request against `main`.
