# Conventions

## Files
- Markdown only, one topic per file.
- File names are lowercase with hyphens: `getting-started.md`, not `Getting Started.md`.

## Commits
- First line under 72 characters, in the imperative: "Add FAQ", not "Added FAQ".
- One logical change per commit.

## Branches
- `main` is always in a working state.
- Feature branches are short-lived and deleted after merge.
